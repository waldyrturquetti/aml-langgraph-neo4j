This is a study project: a money laundering alert triage agent 
(AML - Anti-Money Laundering) using LangGraph for orchestration 
and Neo4j as the graph database. Programming language: Python. 
All data used is fictional, for learning purposes only.

## Language

ALL content generated in this project must be in English, including:
- Markdown documents (proposal.md, design.md, tasks.md, specs)
- Code comments
- Function and class docstrings
- Variable, function, and file names
- Log messages, errors, and prints
- Node names and state fields in the LangGraph graph
